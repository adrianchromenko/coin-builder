# Brand assets

Drop the Coins for Anything logo here. Any of these work:
- logo.png  (preferred, transparent background)
- logo.svg
- logo.jpg

The header uses logo.webp. Replace that file to update the logo.

The turning gold coins carry the logo on their back as logo-coin.webp, which is built from logo.webp:
run `npm run coin-logo` after replacing the logo, and commit the result.
