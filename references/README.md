# Reference coins

Drop photos of real coins here (JPG, PNG, or WEBP). The app sends a few of these
along with each customer image so the AI matches our coin style.

Tips:
- Straight-on, well-lit, one coin per photo, no hands or packaging.
- File names can be anything.
- Optional: sort by finish into subfolders (gold, silver, copper, antique-gold,
  antique-silver, black-nickel). Photos in a matching subfolder are preferred;
  photos in this top folder are used for any finish.
